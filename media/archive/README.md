# Archived laboratory footage

These files are optimized derivatives of `../osiris-coding-hero.mp4`, but the
source depicts a laboratory pipette and microplate rather than coding or web
design work. They are retained only as a technical archive and must not be
connected to the production OSIRIS hero.

- `osiris-lab-pipette-1600.mp4`: H.264, 1600x900
- `osiris-lab-pipette-1600.webm`: VP9, 1600x900
- `osiris-lab-pipette-960.mp4`: H.264, 960x540
- `osiris-lab-pipette-960.webm`: VP9, 960x540
